# 下一版：持续提醒、应用内更新与开源

基线：`f8df7df`（0.5.5）。来源为用户在当前开发会话中的请求。

## 通知

- 最高优先级提供长振动；订阅可选择持续提醒，默认关闭。文案区分长振动与系统可重复的声音/振动，不承诺绕过渠道设置、勿扰或厂商限制。
- 只对符合订阅条件的新消息提醒；缓存重放与异步图标刷新不重新开始持续提醒。
- 打开、清除、已读、删除、静音、移除订阅或停用相关服务后停止对应提醒。多服务互相隔离。
- 旧配置可迁移；已有通知渠道中用户关闭的提醒不能被无提示重置。

## 应用内更新

- 设置内主动检查本仓库最新正式 Release，显示当前/最新版本。
- 用户选择更新后展示下载进度，可取消、失败可重试；下载不得携带 ntfy 凭证。
- 校验来源、校验和、包名、版本与签名兼容性，拒绝损坏或错误安装包和降级。
- 下载成功后交给 Android 系统安装；首次需未知来源授权，安装仍需系统确认，不承诺静默安装。
- 无签名文件或下载缓存意外暴露；FileProvider 仅授权专用缓存目录。

## 开源和交付

- 项目按 Apache-2.0 开放，保留第三方许可证和署名，提供贡献、安全与隐私说明。
- 公开仓库前检查当前文件与可达提交历史中的敏感材料；测试示例与真实凭据分开判断。
- 保留现有顶部筛选、搜索及主题菜单；不改 TLS/DNS 网络行为。
- 不运行模拟器或操作个人设备，不向真实 ntfy 主题发送测试。自动化构建、单元测试与 lint 通过后由已有 Orca reviewer 审查；设备未测部分如实说明。
