# 应用内更新（0.6.0）

入口：设置 → 检查更新。主动读取 `marlonfan/perch-android` 最新非 draft、非 prerelease 的 GitHub Release，不轮询、不携带 GitHub/ntfy 令牌。版本按三个整数比较；GitHub Release 必须包含与标签一致的 `Perch-<版本>.apk` 和 `SHA256SUMS.txt`。仓库未公开或无正式版本时会提示原因。

确认“下载并安装”后展示字节进度，可取消与重试。下载失败/取消会清理临时文件；最大 APK 150MiB，发布信息 1MiB，校验清单 64KiB。HTTPS 下载仅允许精确仓库资产及 GitHub release-assets CDN 跳转，不允许明文、凭据 URL、任意主机或其他仓库路径。

安装前验证文件长度、SHA-256、包名 `app.perch`、versionName 与 Release 一致、versionCode 高于已安装版本、minSdk 不高于设备以及签名兼容性。Android 9+ 单签名升级允许系统解析出的证书轮换历史包含当前签名；多签名需签名集合完全一致，Android 8 不采用轮换。系统安装器仍执行其签名与安装安全校验。调试版与正式版签名不同可能无法覆盖安装。

校验成功自动交给系统安装。未授权未知来源时需先点击“允许安装”并完成 Android 设置；授权返回后重新校验并打开安装页。拒绝授权、取消安装、返回页面都不会自动循环弹窗。安装器已打开不代表安装成功，界面如实显示“已交给系统安装”。再次安装需用户明确点击。

FileProvider 仅暴露 `cache/updater/`，只向安装器临时授予验证后 APK 的读取权。退出设置会取消未完成任务与清理未交接文件；交接后的文件保留，防止安装器读取时被删，后续下载清理两天前缓存。进程退出后不自动恢复下载/安装；重新检查即可。

JVM 覆盖版本、来源、校验清单、签名策略、安装包身份与升级条件，以及取消/重试、验证失败清理、授权拒绝、安装前重验证和交接后保留文件。未操作设备、未跑完整下载安装：未知来源授权、系统安装器、实际签名档案与旋转/渠道行为仍需真机验证。
