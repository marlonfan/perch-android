# 栖信 0.5.0

补齐 ntfy 的消息交互及常用客户端功能。可覆盖安装 0.4.0，保留已有服务、订阅、本地消息、已读和删除记录。

- 通知点击打开消息指定的网站或 App；收件箱仍可进入详情。
- 系统通知及详情支持打开链接、HTTP 回执、复制指定内容、Android 广播按钮。HTTP 操作显示执行状态，成功后才按消息配置清除通知；广播需在订阅设置中开启。
- 支持标签/Emoji、自定义消息图标、附件信息、文件下载、图片预览、系统打开与分享。单文件上限 25 MB。
- 支持 sequence_id 消息更新及服务端清除/撤回事件，按服务与主题隔离，处理缓存重放。
- 支持多个 ntfy 服务同时接收，切换收件箱、独立暂停与移除。
- 新增消息发送表单：标题、正文、优先级、标签、Markdown、URL 附件、文件上传；支持 Android 文本及文件分享至主题。
- 新增消息搜索、订阅最低提醒优先级及提醒标签条件、ntfy:// 订阅链接。
- 服务令牌与操作按钮数据本地加密，HTTP 按钮不继承订阅凭证。

下载此 Release 的 Perch-0.5.0.apk 安装，SHA256SUMS.txt 可校验文件完整性。

本版按用户要求不做本地模拟器或实体手机验证；发布前进行代码审查，GitHub Actions 执行单元测试、Lint、签名构建及 APK 签名验证。通知及时性仍受 Android 和厂商后台策略影响，附件有效期取决于发送方或 ntfy 服务配置。
