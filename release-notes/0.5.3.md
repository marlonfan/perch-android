# 栖信 0.5.3

收件箱更紧凑，并调整 Clash/VPN 场景的联网路径与 TLS 诊断。可直接覆盖安装 0.5.2，保留连接配置、本地消息与操作记录。

- 「全部标为已读」改为右下角双勾悬浮图标，仅有未读且非多选时显示；标记当前服务全部消息，保存成功后清除对应通知。
- 顶部筛选压缩为一行，主题通过右侧筛选图标切换；单主题筛选有圆点和菜单勾选提示。发送消息移至筛选菜单。
- 撤回 0.5.2 的显式 Network DNS/socket 绑定，恢复 Android 默认联网路径；保留网络变化重连、独立连接池和游标补收。
- 区分证书有效期、证书链、对端身份、协议、握手及 TLS IO 错误。设置新增「最近连接错误 · 点击复制」，便于反馈诊断码；摘要仅保存在内存，不包含服务地址或令牌。

Reviewer（Orca Worker）审查通过，无 P1/P2 阻断；本地 41 项 JVM 测试、Debug 构建与 Release Lint 通过。发布工作流执行测试、Lint、签名构建与 APK 签名验证。

本轮未操作实体手机或运行模拟器。默认联网路径回退是兼容性调整，尚未确认手机 Clash 下 TLS 故障的根因或修复效果，证书与主机名校验保持开启。若仍连接失败，请在开启 Clash 时到设置复制最近连接错误，并反馈诊断码。
