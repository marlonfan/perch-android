# 0.5.1 消息展示调整

2026-10-29，基线 v0.5.0。用户确认所指为 tags 对应的 Emoji，而不是消息自定义 icon 图片；要求移到标题前，并优化消息详情里打开链接等圆形 / 胶囊按钮。

## 标题

- 已知 Emoji 标签在标题前内联显示，字号跟随标题；收件箱、详情、系统通知一致。
- 相同 Emoji 的别名不重复占位；未知 / 普通文字标签保留为文字。
- 不改写保存的标题和标签，不改变搜索、提醒匹配及通知优先级。
- 自定义 icon 图片与 App 小图标不参与本次位置调整。

## 操作区

- 详情使用整齐的全宽操作行，外层 14dp 圆角，分隔线区分多个操作，取代零散的胶囊按钮。
- 每行显示动作图标、原始操作名称及简短说明。链接仅显示主机名，不展示查询参数或 HTTP 凭证。
- 点击区域至少 64dp 高，名称和说明可换行，失败原因完整显示；支持浅深主题及读屏按钮语义。
- 执行中禁用重复点击并显示进度；成功显示勾选；失败保留手动重试入口。没有可复制内容时禁用复制操作。
- 消息 click 与显式 view 操作地址完全相同时隐藏重复的 click 入口，保留显式操作及其状态、clear 语义。
- 附件按钮使用 10dp 圆角、至少 48dp 点击高度，并在窄屏自动换行。
- HTTP 请求、超时、凭证隔离、广播授权、clear 行为和通知渠道保持既有实现；不改系统通知按钮模板。

## 验证与交付

不运行模拟器、不操作实体手机、不向用户 ntfy 主题发送消息。运行既有 JVM 单元测试、Debug 构建及 Release Lint；Reviewer（Orca Worker）只读审查后，通过 GitHub Actions 发布 v0.5.1 签名 APK。
