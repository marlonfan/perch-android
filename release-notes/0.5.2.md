# 栖信 0.5.2

修复网络配置变化后的后台接收，并让「全部标为已读」更容易找到。可直接覆盖安装 0.5.1，保留连接配置、本地消息与操作记录。

- Clash / VPN / TUN 或同网络的 DNS、路由配置变化时，自动取消旧消息流、重建连接，并通过已有游标补收缓存消息。
- 等待新网络的 DNS 和路由配置就绪后再连接；每次接收会话使用独立连接池，DNS 解析与 socket 使用同一系统默认网络。
- 连接失败时分别提示 DNS 解析失败、网络超时、服务器连接失败或 TLS 失败，便于检查代理设置。
- 收件箱筛选区直接显示「全部标为已读」文字按钮，无需打开主题菜单；点击标记当前服务的全部消息并清除对应通知，无未读时自动禁用。
- 调整筛选区布局，长主题名自动省略，给「全部标为已读」保留独立空间。

两项修改均经 Reviewer（Orca Worker）审查通过，无阻断问题；本地 37 项 JVM 测试、Debug 构建与 Release Lint 通过。发布流程通过 GitHub Actions 执行单元测试、Lint、签名构建与 APK 签名验证。

本轮未操作实体手机或运行模拟器。已修复应用侧网络回调与连接处理缺口，Clash 真机效果仍待复测；如代理规则拒绝访问、Fake-IP 映射异常或证书拦截，仍需检查对应 Clash 设置。

下载 `Perch-0.5.2.apk` 安装，`SHA256SUMS.txt` 可校验文件完整性。
