# 栖信 0.5.1

优化消息标题与操作区。可直接覆盖安装 0.5.0，保留配置、本地消息和操作记录。

- Emoji 标签（例如 ⚠️、✅、🔥）放到消息标题前，与标题同字号，列表、详情与系统通知保持一致。
- 普通文字标签仍然保留；只改变显示方式，不改写标题、原始标签、搜索或提醒筛选条件。
- 将详情里的胶囊按钮替换为整齐的圆角矩形操作区，每行显示动作图标、操作名称及目标网站。
- 执行中显示进度，成功显示勾选，失败显示原因并可手动重试；长文本自动换行。
- 消息链接与显式打开操作指向相同地址时，只保留显式操作入口。
- 附件下载、打开、分享、预览按钮统一为小圆角矩形，并在窄屏下换行。

系统通知的按钮样式仍由 Android / 手机系统控制。消息自定义 icon 图片和栖信 App 图标保持原有用途。

按用户要求不运行本地模拟器或操作实体手机；发布前进行代码审查，GitHub Actions 执行单元测试、Lint、签名构建及签名验证。下载 Perch-0.5.1.apk 安装，SHA256SUMS.txt 可校验文件完整性。
